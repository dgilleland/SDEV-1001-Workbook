# Debugging with Breakpoints

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. The starter has an intentional logic bug. Calculate the expected total for three $4 tickets with a $2 discount applied once to the whole order.
2. Set a breakpoint on the total calculation in your editor. In VS Code with the Python and Python Debugger extensions installed, click beside the line number, then choose Run and Debug > Python Debugger > Python File. Other IDEs have equivalent controls.
3. Step over the calculation and inspect quantity, unit_price, discount, and total. Record expected and actual values in notes.md before editing.
4. Explain the faulty assumption, correct the calculation, and rerun it. Also check a zero discount.

## Check your work

- The corrected total is $10.
- Your notes show an observed value before the fix and a result after it.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
