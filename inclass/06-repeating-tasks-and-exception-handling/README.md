# Repeating Tasks and Exception Handling

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. Use a for loop to display the supplied daily targets.
2. Plan a while loop that asks for whole-number minutes or done. Check for done before converting the response.
3. Catch ValueError around integer conversion and allow another attempt. Reject negative minutes without adding them.
4. Accumulate accepted minutes and show the total when the loop ends. Keep the try block focused on conversion.

## Check your work

- Inputs 10, oops, -2, 15, done produce 25 minutes.
- Entering done first produces 0.
