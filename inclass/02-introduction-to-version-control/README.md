# Introduction to Version Control

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. From the workbook root in your own clone, run git status. Do not initialise a nested repository.
2. Add a learning goal to this topic's notes.md. Run git diff -- inclass/02-introduction-to-version-control/notes.md. An untracked file appears in status but not in this diff yet.
3. Stage just that file with git add inclass/02-introduction-to-version-control/notes.md. Inspect git diff --cached before committing; keep unrelated work out of this commit.
4. Use git commit with a descriptive message. Revise your goal, inspect the difference, then stage and commit that revision.
5. Run git log -2 --oneline -- inclass/02-introduction-to-version-control/notes.md and connect the messages to your changes. If Git requests an identity, follow your instructor's setup directions.

## Check your work

- Your file has two meaningful commits.
- You can explain the working tree, staging area, and commit history.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
