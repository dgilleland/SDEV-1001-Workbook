# Dictionaries (Key-Value Pairs)

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. Inspect the supplied dictionary. Identify keys and values; notice that we look up quantities by name.
2. Read the pens quantity, update it, and add a new item.
3. Ask for an item name. Handle an unknown key using membership testing or get().
4. Use items() in a loop to display all items and quantities.

## Check your work

- An existing item displays its current quantity.
- An unknown item gives a helpful message rather than KeyError.
