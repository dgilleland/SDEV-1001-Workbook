# Working with Arrays (Python Lists)

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. We'll use Python lists for introductory array-style work. These are not the same type as array.array or NumPy arrays. Predict the supplied list's length, then print its length and first and last items.
2. Append one supply and replace the second item. Notice that indexes start at 0.
3. Remove one known item and display the final list.
4. Temporarily try an index equal to the list's length. Observe IndexError, then remove that experiment from the working script. Loops are not required yet.

## Check your work

- The final list includes your added item and replacement.
- You can explain why a three-item list has indexes 0, 1, and 2.
