# Introduction to Programming

Let's explore this topic together. Follow the [track setup](../README.md), then open the supplied starter files.

## Explore together

1. Predict what the supplied print statement does, then run it. Python executes statements in order.
2. Ask for a name and favourite activity using input(). Store the responses in variables.
3. Ask for whole-number practice minutes per day. Convert the response with int() and calculate the minutes for five days.
4. Display an introduction and the calculated total. For now, assume valid non-negative numeric input.
