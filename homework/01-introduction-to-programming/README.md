# Introduction to Programming

This is independent, ungraded practice after the matching in-class activity. Follow the [track setup](../README.md).

## Your task

Build a trip-time calculator. Ask for a destination, whole-number travel minutes each way, and a whole-number number of visits. Display the total travel minutes. Use named variables, input(), integer conversion, arithmetic, and print(). Assume valid non-negative integer input; decisions and validation come later.

## Check your work

- A 15-minute journey each way over 3 visits totals 90 minutes.
- Zero visits produces 0 minutes.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
