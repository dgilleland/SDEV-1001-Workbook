# Repeating Tasks and Exception Handling

This is independent, ungraded practice after the matching in-class activity. Follow the [track setup](../README.md).

## Your task

Create a whole-number guessing game using the supplied fixed secret. Repeat until the user guesses correctly; report too low or too high for other integer guesses. Recover from non-numeric input by catching ValueError. Count only valid integer guesses. Keep the fixed secret so checks are repeatable.

## Check your work

- Inputs hello, 2, 9, 7 finish with 3 valid guesses.
- Guessing 7 first finishes with 1 valid guess.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
