# Introduction to Version Control

This is independent, ungraded practice after the matching in-class activity. Follow the [track setup](../README.md).

## Your task

Keep a learning journal in notes.md. Record one programming question, then revise it after trying an example. Capture the changes in two separate commits in your own workbook clone. Run Git commands from the workbook root. Use git status, git diff, git add, git commit, and git log. Stage only this notes file, and inspect all staged changes before committing. No push, branch, or nested repository is needed.

## Check your work

- Two descriptive messages explain the journal changes.
- You can distinguish saving a file from committing it.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
