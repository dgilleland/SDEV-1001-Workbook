# Homework Starter Kits

Independent practice after the matching in-class activity. Use your notes and bring questions back to class. All activities are ungraded. These are unfinished starters, not completed examples. Numbers suggest an order, not a weekly schedule.

## Getting started

Use the Python 3 installation and editor selected by your instructor. Read the topic README, then open a terminal in that topic folder. Run ordinary starters with `py main.py` on Windows or `python3 main.py` on macOS/Linux. If your installation uses `python` for Python 3, use that instead.

TODO comments and `pass` mark work you will complete. A starter may run without producing output. The debugging starters contain deliberate bugs. Package topics have separate setup instructions; the version-control topic uses Git commands from the workbook root.

Keep your edited files and record predictions, observations, and questions in notes.md. No workbook activity is submitted for marks.
