# File Reading and Writing

This is independent, ungraded practice after the matching in-class activity. Follow the [track setup](../README.md).

## Your task

Read daily practice minutes from data/minutes.txt. Skip blank lines; skip invalid integers with a message. Write the total to report.txt. Use with blocks, UTF-8, and write mode. Handle a missing input file with a useful message rather than a traceback. Run from this folder and use relative paths.

## Check your work

- The supplied file totals 45 minutes and reports one invalid entry.
- Running twice does not duplicate the report.
- A missing input file produces a useful message.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
