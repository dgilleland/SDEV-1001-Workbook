## Your task

Complete ScoreCounter in counter.py. Each instance needs a name and a score starting at zero. add(points) increases its own score; reset() returns it to zero. Exercise two counters from main.py. Assume points is a non-negative integer; input validation is outside this exercise.

## Check your work

- Adding 3 then 2 to one counter gives it 5 points.
- The other counter remains at 0.
- Resetting the first returns it to 0.
