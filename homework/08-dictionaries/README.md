# Dictionaries (Key-Value Pairs)

This is independent, ungraded practice after the matching in-class activity. Follow the [track setup](../README.md).

## Your task

Create a small contact lookup. Add a contact, update one extension, and let the user look up a name. Handle unknown names and display the directory with a loop. Keep extensions as strings to preserve leading zeros. Exact name matching is acceptable; say so in your prompt.

## Check your work

- Extension 0042 retains both leading zeros.
- An unknown name gives a helpful message.

Keep your edited starter files and add a prediction, an actual result, and a question or discovery to notes.md. Nothing here is submitted for marks.
